Widget preview

This page stands in for barndobible.com. The floating Ask BarndoBible button sits in the bottom-right corner.

To add the floating button to every page of the site, paste this into WPCode as a site-wide footer snippet:

<script src="https://api.barndobible.com/widget/barndo-agent.js" defer></script>

To place the widget inside a page instead (for example on a tools page, opened on the estimator), add a Custom HTML block with <div id="barndo-estimator"></div> and load the script with data-inline="#barndo-estimator" data-tab="estimate".
